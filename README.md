## 🧪 Security Labs

### Lab 1 — SIEM Setup and Monitoring

> Deployed and configured Splunk for security event monitoring. Simulated log clearing and failed login attempts to validate detection rules and alerting.

- **Tools:** Splunk, Windows Event Manager
- **Outcome:** Detected simulated attacks through custom Splunk alerts and dashboards
- 📹 [Watch the walkthrough](https://www.youtube.com/watch?v=QhVx4lV4IQk)

---

### Lab 2 — Vulnerability Scanning

> Conducted a full network vulnerability scan using Nessus — mapping all assets on the network and identifying high-risk vulnerabilities across devices.

- **Tools:** Nessus
- **Outcome:** Discovered 14 high-risk vulnerabilities on a single device — remediated 1 critical finding
- 📹 [Watch the walkthrough](https://www.youtube.com/watch?v=1aIY9tGRVtM)

---

### Lab 3 — Network Traffic Analysis

> Captured and analysed live network traffic to identify suspicious outbound connections from a compromised virtual machine.

- **Tools:** Tcpdump, Wireshark
- **Outcome:** Identified suspicious outbound traffic, isolated source IP, and analysed potential data exfiltration pattern

---

### Lab 4 — Web Application Attacks

> Simulated OWASP Top 10 attacks against a vulnerable web application — SQL Injection and Cross-Site Scripting (XSS).

- **Tools:** Kali Linux, Burp Suite
- **Outcome:** Successfully exploited and documented vulnerabilities — proposed secure coding countermeasures for each finding

---

### Lab 5 — Phishing Incident Response

> Simulated a spear phishing attack and full incident response — from initial compromise through root cause analysis and reporting.

- **Tools:** Email header analysis, forensic investigation tools
- **Outcome:** Traced attack chain, identified compromise point, produced incident summary and remediation report
- 📹 [Watch the walkthrough](https://youtu.be/7m7Va6tINVE)

---

### Lab 6 — Jira SOC Ticket Workflow

> Modelled a real-world Security Operations Centre (SOC) ticket workflow using Jira — logging simulated incidents and tracking remediation through to closure.

- **Tools:** Jira
- **Outcome:** Built a structured security ticket workflow covering detection, triage, remediation, and closure — demonstrating SOC analyst process knowledge
